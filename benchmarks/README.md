# Medical Benchmark Data

This directory contains the local benchmark data used by HealthCoreBench. Language-model
benchmarks are stored under [`medical_llm_benchmarks/`](medical_llm_benchmarks/), and
vision-language-model benchmarks are stored under
[`medical_vlm_benchmarks/`](medical_vlm_benchmarks/). The numbered entries in the tables
below correspond directly to the numbered local dataset directories.

The **Samples** column reports the number of samples in the medical-related tasks selected
for evaluation, rather than necessarily the size of every split published by the dataset
authors.

> **Data availability note:** Some benchmark source data is inaccessible or only partially
> available. Consequently, local sample counts can differ from the counts reported in the
> original papers. The benchmark data itself is intentionally excluded from Git; only this
> inventory is version-controlled.
